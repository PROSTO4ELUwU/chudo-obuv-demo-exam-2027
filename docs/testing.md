# Ручная проверка системы «Чудо Обувь»

План проверки по заданиям КИМ с ожидаемыми результатами. Один и тот же план
проходится на обеих версиях: `bin\python\ChudoObuv.exe` и `bin\cpp\ChudoObuv.exe`.

Ожидаемые значения рассчитаны на исходных данных заказчика. Перед проверкой
и после неё базу удобно вернуть в исходное состояние скриптом `database\deploy.bat`.

Логины: `isivanov` — администратор, `papetrov` — менеджер,
`asidorova` — авторизованный пользователь (клиент).

## 1. Вход в систему (задание 3)

- [ ] Нажать «Войти» с пустым полем — окно «Предупреждение»: «Введите логин…».
- [ ] Ввести `petrov` — окно «Ошибка»: «Пользователь с логином «petrov» не найден…».
- [ ] Попробовать ввести логин русскими буквами — символы не вводятся,
      появляется подсказка проверить раскладку клавиатуры.
- [ ] «Войти как гость» — каталог **без** панели поиска и фильтров, в правом верхнем
      углу «Гость» и кнопка «Войти», нажатие на карточку ничего не открывает.
- [ ] Войти как `asidorova` — в правом верхнем углу «Сидорова Анна Дмитриевна»
      и «Авторизованный пользователь», кнопка «Выйти».
- [ ] Заголовок окна меняется по страницам: «Чудо Обувь — Вход в систему»,
      «Чудо Обувь — Каталог товаров» и т. д.

## 2. Каталог товаров (задание 2)

- [ ] В каталоге 31 карточка. В каждой: изображение, «Производство | Наименование»,
      категория, количество, состав, цена.
- [ ] Подсвечены цветом `#FF8080` ровно три товара (осталось три пары и меньше):
      «Женские босоножки «Черный кофе»…» (3), «Туфли из натуральной кожи» (3),
      «Ботинки мужские демисезонные» (2).
- [ ] «Мало», но без подсветки (4 пары): «Кроссовки детские «Гонщик»»,
      «Сапоги осенние натуральная кожа», «Кроссовки белые с оранжевым и красным».
      У остальных — «много».
- [ ] Скидка: в исходных данных все заказы сделаны в апреле–мае, поэтому в прошлом
      месяце заказов нет и скидка 25 % действует на **все** товары — новая цена
      и зачёркнутая старая (например, «Звёздочка»: ~~2 190,00 ₽~~ 1 642,50 ₽).
      Как увидеть товар без скидки — в разделе 5.
- [ ] Оформление: шрифт Calibri, шапка цвета `#D2F6E7` с логотипом, кнопки целевых
      действий цвета `#70B2AF`, иконка приложения на панели задач.

## 3. Поиск, фильтр и сортировка (задание 3, войти как `asidorova`)

- [ ] Поиск «звездочка» (без «ё», любым регистром) находит «Кроссовки детские
      «Звёздочка» экокожа».
- [ ] Поиск «смоленск» находит ту же модель — поиск идёт и по описанию.
- [ ] Поиск «зимние» — 3 товара: «Сапожки детские «Снежинка»…», «Сапоги зимние
      натуральная кожа», «Ботинки зимние классические».
- [ ] Первый пункт фильтра — «Все категории»; «Детская обувь» — 9 товаров,
      «Женская обувь» — 13, «Мужская обувь» — 9.
- [ ] «Цена по возрастанию»: первым «Сандалии детские «Морячок»…» за 1 267,50 ₽;
      «Цена по убыванию»: первыми «Туфли из натуральной кожи» за 19 218,75 ₽.
- [ ] Всё применяется сразу, без кнопки «Найти»; фильтр и поиск работают вместе,
      а выбранная сортировка сохраняется при смене фильтра и поиска.
- [ ] Поиск без результатов — подсказка «Товары не найдены…» и «Найдено: 0 из 31».

## 4. Оформление заказа (задание 3, войти как `asidorova`)

- [ ] Нажать на карточку «Гонщика» — форма товара: изображение, производство,
      наименование, категория, цена со скидкой (1 867,50 ₽), состав, описание,
      размерный ряд «33, 34», доступные размеры «33 — 2 пары; 34 — 2 пары».
- [ ] Ввести в поле количества 99 — поле не даёт выйти за остаток (максимум 2).
- [ ] «Добавить в заказ» 1 пару размера 33 — вопрос «Оформить заказ / Продолжить выбор».
      Выбрать «Продолжить выбор».
- [ ] Снова открыть «Гонщика» — для размера 33 теперь доступна 1 пара
      (учтена пара, уже добавленная в заказ). Вернуться «Назад».
- [ ] Кнопка «Формируемый заказ: 1 пара» — таблица заказа, клиент — Сидорова А. Д.
      Изменить количество, удалить позицию (с подтверждением), посмотреть итог.
- [ ] Добавить «Гонщика» снова и «Подтвердить заказ» — сообщение
      «Заказ №11 от <сегодня> оформлен…». Каталог обновился: у «Гонщика» осталось
      3 пары, и карточка **стала подсвеченной**.
- [ ] «Отказаться от заказа» — подтверждение, позиции удаляются.
- [ ] Добавить товар и нажать «Выйти» (или закрыть окно) — запрос подтверждения,
      что неподтверждённый заказ будет потерян.

## 5. Работа с заказами (задание 4)

Менеджер (`papetrov`):

- [ ] В каталоге есть кнопка «Заказы». Список: номер, дата, ФИО клиента, сумма,
      новые заказы сверху.
- [ ] «Состав заказа» без выбора — предупреждение «Выберите заказ в списке».
- [ ] Двойной щелчок по заказу №1 — состав: «Кроссовки детские «Звёздочка» экокожа —
      Малыш-Спорт», размер 20, и «Сандалии детские «Пчёлка»…», размер 22,
      по 1 паре; итог 4 980,00 ₽. Кнопок редактирования у менеджера нет.
- [ ] «Добавить заказ» — каталог «Выбор товаров для заказа», без кнопки «Заказы».
      Найти товар поиском, открыть, добавить, выбрать «Оформить заказ».
- [ ] Подтвердить без выбора клиента — предупреждение; выбрать клиента и подтвердить —
      возврат **в список заказов**, новый заказ сверху (обычно №12).
- [ ] Выделить этот новый заказ и «Удалить заказ» — подтверждение; заказ исчез,
      пары вернулись в остатки (видно в каталоге).

Администратор (`isivanov`):

- [ ] В составе заказа есть поле даты и «Сохранить дату» (активна только после
      изменения даты); дату позже сегодняшней выбрать нельзя.
- [ ] **Проверка скидки:** изменить дату заказа №1 на любой день прошлого месяца
      (например, 15.09.2026) и сохранить. В каталоге у «Звёздочки» и «Пчёлки»
      скидка пропадёт: 2 190,00 ₽ и 2 790,00 ₽ без зачёркнутой цены — по ним
      теперь есть заказы в предыдущем календарном месяце. В форме товара
      вместо «Цена со скидкой:» будет просто «Цена:».
- [ ] В заказе №4 (5 позиций) удалить позицию — подтверждение, сумма пересчиталась.
- [ ] В заказе «Гонщика» из раздела 4 (обычно №11, в нём одна позиция) нажать
      «Удалить позицию» — сразу запрет: «Это единственная позиция заказа…».
- [ ] После изменений список заказов обновлён (дата и сумма).

## 6. Последовательный интерфейс и ошибки

- [ ] «← Назад» возвращает на предыдущую страницу на любом шаге, на главной
      странице кнопки «Назад» нет.
- [ ] Окна сообщений разных типов с соответствующими заголовками и значками:
      «Ошибка», «Предупреждение», «Информация», «Подтверждение», «Вопрос».
- [ ] Недоступная база: остановить службу `postgresql-x64-17` (Службы Windows,
      нужны права администратора) и запустить программу — сообщение «Не удалось
      подключиться к базе данных…» с подсказкой, программа не падает. Если остановить
      службу во время работы, действие завершится сообщением об ошибке базы, а после
      запуска службы программа продолжит работу. Службу не забыть запустить снова.
